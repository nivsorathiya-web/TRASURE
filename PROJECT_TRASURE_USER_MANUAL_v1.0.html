02 MODULE 1: ACCESS CONTROL & SECURITY PROTOCOL

Corporate Authentication & Workspace Login

Enterprise access to TRASURE utilizes a streamlined, credentialed portal designed to prevent unauthorized trading while providing instant role-based access for verified industrial plants.

Step-by-Step Login Sequence

  1. Launch Portal: Navigate to https://trasure-phi.vercel.app in any modern browser.
  2. Select Role Mode: Click the Sourcing Buyer or Listing Seller tab based on current operational context.
  3. Choose Plant Profile: Select your registered entity from the dropdown (e.g., Ambuja Cements Ltd).
  4. Enter Access PIN: Input your 4-digit security PIN (default credential: 1234).
  5. Outbid Notifications: Ensure "Enable WhatsApp bidding & outbid alert updates" is checked for real-time tender feeds.
  6. Authorize: Click Access Corporate Console → to enter the dashboard.

Security Rules & Session Management

  • Brute Force Lockout: 5 consecutive invalid PIN attempts triggers a 15-minute workstation freeze.
  • Session Isolation: Corporate context persists in secure browser memory (localStorage) with auto-expiry.
  • Audit Logging: Every authentication event records client IP, UTC timestamp, and corporate authorization hash.
  • SPCB Sync: Only plants holding an active SPCB consent-to-operate certificate are permitted to bid on hazardous material lots.

Landed Cost Formula

Landed Cost = Ex-Plant Rate + (Road Dist × ₹2.01/km/MT) + 2% Clearing

Eliminates post-purchase freight surprises by accounting for highway toll corridors and axle weight limits.

Routing Engine Specification

  • Router API: Open Source Routing Machine (OSRM) driving profile.
  • Highway Corridors: Prioritizes National Highway (NH) 4-lane and 6-lane expressways over state roads.
  • Haversine Fallback: Automatic mathematical great-circle fallback if offline: d = 2R × arcsin(√(sin²(Δφ/2) + cos φ1 cos φ2 sin²(Δλ/2)))
  • Transit Calibration: Assumes commercial heavy truck average velocity of 55 km/h with mandatory driver rests.

05. REVERSE AUCTION FLOOR
05 MODULE 4: DYNAMIC PRICE DISCOVERY

Real-Time Reverse Auction & Anti-Sniping Floor

TRASURE's real-time auction engine enables buyers to tender procurement contracts while pre-vetted industrial sellers submit downward (decremental) competitive counter-bids.

https://trasure-phi.vercel.app/console
LIVE VERIFIED
Figure 6: Live Auction Room — Spent Sulphuric Acid tender (720 MT, ₹1,350/MT reserve), 23:59:09 countdown, live bid logs, and SPCB verification.

Bidding Protocol & Rules

  • Reserve Ceiling: Bids must strictly undercut the current leading rate.
  • Quick-Bid Increments: One-click counter-bidding at -₹50/MT or -₹100/MT.
  • Broadcast Feed: WebSocket/Event-stream updates active leader instantly across all connected terminals.

60-Second Anti-Sniping Rule

If a competitive counter-bid is submitted when the countdown clock displays ≤ 60 seconds, the engine automatically adds +60 seconds to the tender timer, ensuring all participants fair response time.
